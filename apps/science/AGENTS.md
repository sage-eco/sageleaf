# Science App (`apps/science/`) — Agent Rules

**Package Name:** `@sageleaf/science`

## Overview

Nuxt 3-based data management frontend for the Sage platform. Focused on data analysis, visualization, and tools. **Desktop only** — no mobile targets.

## Framework & Architecture

Same stack as `apps/frontend/` (Nuxt 4.x, Vue 3, Apollo GraphQL, DaisyUI/Tailwind, Pinia) but without Tauri mobile integration.

**Key difference from frontend:** Science is desktop-focused with an emphasis on data visualization. Refer to `apps/frontend/AGENTS.md` for shared patterns (Vue/Nuxt component structure, composables, GraphQL usage, routing, state management, styling, i18n).

## Internationalization

Follows the same patterns as `apps/frontend/` — see `apps/frontend/AGENTS.md`. Namespace is `science`. Always co-locate the namespace with the key:

```vue
<!-- template -->
<T ns="science" key-name="nav.dashboard" />

<!-- script -->
const { t } = useTranslate() t.value('nav.dashboard', { ns: 'science' })
```

**English (`en.json`) is the source of truth and may be edited directly** — update the matching key in the same diff. Other language files are managed by Tolgee; translators fill them in via the dashboard, so don't hand-edit them. Run `nx i18n science` to push English keys upstream and pull translated values back.

## Common Commands

```bash
# Development
nx dev science                    # Start dev server

# Build
nx build science                  # Build for production
nx generate science               # Generate static site (dev env)
nx generate:prod science          # Generate static (prod env)

# GraphQL Code Generation (runs automatically as part of build)
nx build science                  # Also regenerates GQL types from schema

# Linting & Formatting
nx lint science                   # Lint with oxlint + ESLint, auto-fix
nx lint:ci science                # Lint for CI (no fixes, fail on warnings)
nx fmt science                    # Format code with oxfmt
nx fmt:ci science                 # Check formatting for CI
```

## GraphQL Types

After API schema changes, regenerate science types:

```bash
nx codegen:schema api             # Regenerate schema from code
nx build science                  # Regenerates GQL types as part of build
```

Note: `nx codegen science` does **not** exist — GQL types are regenerated by `nx build science`.
